# 今天吃什么 v0.8.0

第八版集中收尾日常操作并校对已有配方。仍为300道菜谱（193道家常菜、107道早餐），全部图文离线内置。

## 下载与升级

在 Assets 下载 **cookdaily-v0.8.0.apk**。沿用包名与签名，versionCode=8。先导出备份，再直接覆盖安装；**不要先卸载旧版**。

## 使用改进

- 去掉卡片和详情图片上的重复“AI示意”字样，图片说明统一放在设置中。
- 抽菜结果旁增加“换一道”；筛选仍不自动抽菜。没有匹配时旧结果缩成一行，区分上次结果与当前条件。
- 买菜清单可复制纯文本或打开系统分享选择页。默认只带待买食材，可选择包含已买项；食材用量增加会标出需要重新核对的项。清水、饮用水不列入采购。
- 视频教程入口仍放在详情前部，默认收起为一行，按需展开。保持手机系统选择器打开浏览器或平台应用，不依赖 Chrome。
- 第一次在权限未齐时开始计时，给出一次短说明和设置入口。计时已在前台开始；开启权限后需重新开始，才能安排后台提醒。
- 保留计时按钮节点，避免每秒刷新打断焦点；步骤勾选和筛选切换后保留相应控件焦点。存储失败时不会误报“笔记已保存”或“已加入清单”。
- 调整近期抽选与做菜历史的使用顺序，种类轮换以最后抽到的菜为准。

## 内容校对与边界

校对等待时间、分锅批次、单个成品大小、浅碗深度和过敏原。糯米烧卖总用时纳入4小时泡米，烤碗等留足准备与升温时间；多人份增加制作个数和锅次，保持原尺寸。具体修订与旧进度影响见 [内容审计](https://github.com/leijiangjiang547-arch/jintian-chi-shenme/blob/main/docs/v08-content-audit.json)。

收藏、清单、笔记和未改动步骤的进度保留；步骤修订的菜需重新核对。存储与备份版本仍为3，兼容导入版本1、2、3。图片是生成的成品参考，熟透判断按步骤检查。

自动检查与浏览器验证见 [QA记录](https://github.com/leijiangjiang547-arch/jintian-chi-shenme/blob/main/docs/QA.md)。Android 系统复制/分享选择器、荣耀真机锁屏响铃和实际厨房效果仍需体验确认。本次为试用预发布；未提交应用市场、收费或联系推广对象。
