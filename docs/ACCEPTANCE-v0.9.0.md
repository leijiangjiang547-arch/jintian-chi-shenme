# 第九版手机验收

先在旧版设置导出备份，下载 v0.9.0 APK 直接覆盖安装，不要先卸载。

1. 飞行模式打开首页：340道计数和“查看菜谱”大按钮在筛选之前。点按钮能进入全部菜谱；原收藏、买菜勾选、笔记与有效进度仍在。
2. 设置排除食材和不吃辣后，再从首页进入“查看菜谱”：搜索、用时、菜系等临时发现条件恢复浏览，忌口仍保留。筛选变化不自动抽菜；近似候选不进入随机池。
3. 分别搜索“麻辣豆腐”“韭菜炒旦”“豆付”“蕃茄”，检查近似或别名命中。点候选直接进详情，关闭后原搜索词和条件保留。设置不吃辣或排除豆腐后，近似结果也必须遵守限制。
4. 搜索土豆烧排骨、土豆烧牛肉、梅菜扣肉，检查独立图片、完整食材及7–9步做法。梅菜扣肉应显示4小时40分钟；人数增加时保持肉片厚度和蒸碗层高，增加碗数，不把全部肉堆厚。
5. 首页“告诉我们”或缺菜空状态打开补菜建议。飞行模式填菜名和可选备注，保存、关闭、重开仍在；同名建议更新备注。保存只存在本机，不代表已提交。
6. 点击“复制建议”并粘贴到自己选择的文本应用，检查中文与换行。点击“提交给我们”应可选择手机已有浏览器，联网后到本仓库GitHub草稿；登录和确认由用户完成。内容公开，不填写个人信息，不必为测试实际发布Issue。
7. 导出备份，再导入该文件，检查补菜建议与原个人数据。若需测旧版备份，请先保留当前完整备份；导入版本1/2/3时当前补菜建议应保留。当前计时不进入备份。
8. 在小屏、横屏、深色查看补菜表单和长菜名；按钮可点、内容能纵向滚动、无横向溢出。叠加打开设置和补菜建议时返回应先关闭最上层。
9. 原有抽菜、清单复制/分享、教程返回、计时权限提示继续回归。开启通知与精确计时后重新开始，测切微信、接电话和锁屏；勿扰、音量与厂商省电由手机系统控制。
10. 分批试做新菜，记录真实备料/等待/加热时间、锅具、火力、用料规格、咸淡及难懂步骤。粉条泡发按包装，新鲜/预熟食材前提需核对；加大人数优先增加锅次、碗数，不改变单个规格。

自动检查和桌面浏览器不代表真机或厨房验证。第九版体验通过后，再确定正式发行、反馈后台和商业化投入。
