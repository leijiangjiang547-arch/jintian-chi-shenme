# 第八版手机验收

先在旧版设置导出备份，下载 v0.8.0 APK 直接覆盖安装，不要先卸载。

1. 飞行模式打开首页、列表和详情：300道图文应可看，每张图没有重复标签；设置可展开一次图片说明。
2. 选家常菜＋15分钟，点击抽菜；在结果旁点“换一道”。修改筛选不自动换菜；唯一候选与零候选状态应明确。
3. 将两道菜加入清单，勾一项。复制时默认只有待买食材；关闭“只复制 / 分享待买食材”后包含已买项。将文本粘贴到自己选择的文本应用，核对换行与用量。
4. 点击分享应先出现手机系统选择页；取消后仍保留清单与勾选。应用不会自动发送给任何人。不必为了验证联系他人。
5. 增加人数后仅用量增加的已买项取消勾选；增加项有核对标记。减少人数后其他勾选保留。
6. 打开菜谱，视频入口在前部且默认收起，点开再见平台入口。用手机现有浏览器或平台应用打开，返回应回到原详情。
7. 若未开计时权限，第一次开始计时应有短说明；可继续前台或进入设置。开启通知与精确计时后**重新开始**，分别测切微信、接电话和锁屏。计时结束检查通知、声音、振动及返回后的剩余时间；勿扰与音量由系统控制。
8. 做菜模式横屏、深色与触控锁：下一步易点，双击解锁后可操作，手势条不遮按钮。关详情再打开，有效进度应保留。
9. 旧收藏、清单、笔记、未变步骤进度仍在；步骤有修订的菜提示重新核对。备份导出/恢复能保留这些记录，当前计时不在备份中。
10. 分别以1、2、4人实际试做高频菜，并记下锅具、火力、尺寸、实际等待/加热时间、口味和难懂步骤。尤其抽查糯米烧卖、吐司夹馅、饭团和煎饼，人数变化应增加个数或批次，不能把单个成品加厚。

自动测试和桌面浏览器不替代以上设备和厨房验证。第八版体验通过后再讨论发行渠道、上架与收入模型。
