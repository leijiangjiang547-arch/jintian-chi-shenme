# 第五版手机验收

先在旧版设置导出备份，再覆盖安装。无需卸载。以下项目留待真实手机确认，不把浏览器测试视为通过。

1. 核对原收藏、人数、清单勾选；版本应为0.5.0。
2. 飞行模式冷启动，查红烧肉、香蕉厚蛋烧、皮蛋豆腐：文字和图片均可见，图片标AI示意。
3. 首页家常菜+15分钟内显示6道，点抽菜后才出现结果；改条件保留上次结果并提示，不跳第一道。
4. 菜系、难度、时间、排除食材、不吃面条、搜索在首页/菜谱/收藏同步；重启后相同。改为早餐清除不适用菜系。
5. 做到第2步退出、切导航、关闭应用再开，能继续；手工勾选保留，重新开始可清除。
6. 导出备份后检查含schema=2与progress；试导入旧版schema=1，旧收藏/清单正常，旧备份没有进度属正常。
7. 深色下图文、横屏步骤、油手触控锁、系统返回、手势条和大字号。
8. 通知与精确计时授权后，切微信、锁屏并等待到时；关闭权限时明确降级。分别在Magic6和荣耀400记录系统版本和结果。
9. 实做至少两道快手菜，记录备料/加热/总时间与难懂步骤；照片须来自本次实做，不用AI图冒充结果。
