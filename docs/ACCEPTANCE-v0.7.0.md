# 第七版体验检查

先导出旧版备份，再覆盖安装，不卸载。应显示版本0.7.0。程序检查不替代下列手机与厨房体验。

1. 原收藏、购物勾选、人数、笔记、步骤进度保留。随机条件仍由用户设置后点抽选；改变筛选不自动换菜。
2. “干锅菜花”“干锅花菜”“ganguohuacai”“gghc”找到同一道菜；“hongshaorou”和“hsr”找到红烧肉，菜名匹配优先显示。搜索“干锅菜华”给出可点候选，不自动更改搜索。
3. 全部菜谱按菜系入口左右滑动，可以选八大菜系及京津、东北、西北风味；类别、难度、用时、忌口仍能叠加，来回切页面一致。
4. 总数300、家常193、早餐107。默认分批显示36道，再看更多正常；搜索后批次重新开始，返回刚看的菜谱仍正常，收藏不会因批次而丢失。
5. 飞行模式重开新菜：干锅菜花、红烧狮子头、荔枝肉、绿豆糕的文字与图片都可见；图片标AI示意。视频入口在材料之前，默认选择打开方式可选手机现有应用并正常返回。
6. 新配方在1/3/6人份下，油盐分次、食材、步骤用量一致；锅小按提示分批，计时不按人数倍增。浸泡、发酵等等待不能被快手筛选忽略。
7. 本机笔记、已做记录、手工勾选续做与备份schema=3正常；旧schema=1/2恢复兼容。完成一道菜取消其应用内计时，其他菜计时保留；系统时钟计时需在那里结束。
8. 在Magic6与荣耀400检查大字号、320px级小屏、深色、横屏、返回与手势条；通知/精确计时权限和锁屏响铃延续第六版检查。
9. 分批实做：先干锅菜花、木须肉等常用菜与一款早餐；记录锅具、备料/加热/总时间、咸淡、难懂步骤、成品照片和修改建议。复杂菜再逐步验，不以AI图当试做结果。

每道菜还有家庭做菜笔记，保存后仅留在本机，可用备份导出。详细来源和编辑边界在仓库审计，应用只保留参考链接与必要操作提示。
