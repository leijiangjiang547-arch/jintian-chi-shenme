# 今天吃什么 v0.5.0

第五版针对第四版使用反馈完善首页流程与离线体验。180道菜谱：100道家常菜、80道早餐。

## 下载

在下方 Assets 下载 **cookdaily-v0.5.0.apk**，约15.9 MB。使用原包名、原签名，versionCode=5。直接覆盖安装，**不要先卸载**；可先在设置里导出备份。

## 主要改进

- 首页顺序为设置条件→查看符合数量→点击抽菜。筛选变化不自动选第一道；保留上次抽选并提示条件已改变。
- 家常菜15分钟内有6道：皮蛋豆腐、现拌黄瓜、蚝油生菜、紫菜蛋花汤、西红柿鸡蛋汤、小葱拌豆腐。用时含两人份常规备料，初次操作、包装处理和多人份可能更久，尚未真人计时。
- 180道内置离线AI成品示意图；飞行模式也能看。明确标注非实拍，配菜/形态以配方为准，不作为熟透判断。
- 首页、菜谱、收藏共享筛选与搜索；不吃面条、菜系、种类等重启后保留。早餐不再假称“早餐菜系”。
- 做菜步骤和勾选按菜谱保存，关闭页面后可继续；支持重新开始，备份也包含进度。
- 全库使用显式用料引用，99道旧菜完成分次油盐迁移；保留时间、尺寸、温度不随人数倍增。
- 首页参考菜按筛选与日期轮换，移除写死ID；中文文案统一；外链http/https交给系统浏览器，其他格式提示。
- 本机数据版本迁移，兼容旧收藏与清单；备份版本2兼容导入版本1。
