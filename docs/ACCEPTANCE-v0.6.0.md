# 第六版手机验收

先在旧版设置导出备份，再覆盖安装，不要卸载。核对版本为 **0.6.0**。以下项目需在荣耀 Magic6、荣耀400上实际确认。

1. **升级与离线**：原收藏、人数、买菜清单及勾选保留；飞行模式冷启动，红烧肉、香蕉厚蛋烧等图片和文字可见。本次修订步骤的23道菜会重置各自步骤进度，收藏及已有笔记不应丢失。
2. **教程入口**：打开菜谱即可看到视频搜索入口，位于食材和步骤之前；无需滚动到底。参考资料折叠可查看，不出现编辑核查过程。
3. **选择打开方式**：默认每次弹出系统选择器，可选手机已有浏览器或平台应用，不依赖 Chrome。选择、取消、外部返回均正常；返回后菜谱和做菜进度保留。设置改为“使用手机默认方式”，重开应用仍保留选择。平台页面可能需要登录，搜索入口不保证直接播放。
4. **首页与收藏**：先设条件再抽菜，改条件不自动换结果。只收藏早餐却筛选家常菜时，仍能看到收藏总数；“查看全部收藏”恢复类别和发现条件，保留排除食材及不吃辣。“重置筛选”同样保留忌口。没有收藏时可直接去找菜谱。
5. **步骤续做**：手工勾选前三步，关闭详情、退出应用再开，继续到首个未完成步骤；取消其中一步勾选后定位相应步骤。全部勾选有明确完成入口；重新开始可清除进度。
6. **完成与计时**：完成一道菜后，其步骤进度清除，属于该菜的应用内计时结束；另一道菜的计时保留。“今天做过”当日重复点击不产生重复记录。交给系统时钟的计时需在系统时钟结束。
7. **后台提醒**：授权通知和精确计时后，切到微信、接电话或锁屏等待到时；检查通知、声音和返回后的剩余时间。关闭相关权限时有明确降级提示。分别记录两台手机的系统版本和结果。
8. **私有笔记与备份**：写下并保存笔记，切页和重启后内容保留；清空后保存可删除。导出文件为schema=3；导入后收藏、清单、进度、笔记及打开方式恢复。旧schema=1/2备份可导入；旧备份未包含的笔记或步骤记录不应被视为恢复成功。
9. **屏幕与返回**：竖屏、横屏、深色、大字号、手势条下关键按钮可见；触控锁、解锁和系统返回正常，教程返回后不丢失当前步骤。
10. **厨房反馈**：实做至少一道家常菜和一道早餐，记录准备、加热、总时间、难懂步骤及实际结果。AI示意图不能替代实做照片或熟透判断。
