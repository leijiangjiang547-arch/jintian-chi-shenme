# 第四版手机验收单

设备：荣耀 Magic6、荣耀400。直接覆盖旧版，不要卸载；安装后先看收藏和买菜清单。

## 必测：系统计时

1. 右上角齿轮 → 通知与声音、精确计时。两项开启后**重新开始**步骤计时。
2. 选择有短计时的步骤，分别测试前台、切微信、锁屏、接电话；记录通知/声音/振动及延迟。
3. 拒绝通知或精确权限后再开始：应明确显示“仅前台提醒”。
4. 结束/替换当前计时后，旧计时不应再通知。点击通知应回到应用。
5. 静音/勿扰、厂商省电可能让通知无声或延迟；强行停止/重启手机后需重新开始。
6. “交给系统时钟”应打开时钟界面；在时钟中核对并启动，取消也须在时钟中完成。

## 必测：数据与清单

1. 加两道有共同食材的菜，勾选已购买。删除一道，剩余食材勾选保留；增加人数，只取消增加用量的食材勾选。
2. 设置一人份，鸡蛋有蛋液克数提示；油盐仍按比例。
3. 设置里导出文件，确认文件管理器能找到。新增一个收藏后导入刚才文件，应先提示替换，再恢复备份的收藏、清单、勾选、偏好、外观、做菜记录。
4. 导入错误JSON/其他文件应拒绝，已有数据不变；取消文件选择器不改变记录。

## 体验

- 搜索“西红柿 鸡蛋”“马铃薯”“hsr”。首字母覆盖菜名和别名，不是完整拼音输入法。
- “湘菜 + 15分钟”空结果显示实际最低用时；取消用时限制后，忌口仍在。
- 横屏做菜检查大按钮、长步骤、滚动、手势条；触控锁不能误进下一步，连续点两次解锁。
- 深色、跟随系统；重开应用外观和收藏保留。完成一道菜后在设置中看到记录。
- 外链在浏览器打开，返回应用仍保留位置；图片是搜索入口，不保证与配方完全相同。

## 验证边界

核心逻辑、174道详情与操作DOM、模拟安卓桥接流程、release混淆构建、签名和APK资源已检查。浏览器连接失败，本轮视觉检查未完成；没有连接手机，后台提醒、系统文件选择器及安全区待真机验证。菜谱未逐道试做。

反馈请附：型号/系统版本、菜名、操作顺序、实际与期待结果。计时问题注明通知、精确计时、勿扰、省电状态。
