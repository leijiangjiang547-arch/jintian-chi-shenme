# 今天吃什么 v0.4.0

第四版重点解决做菜时的可靠性与数据保留，保持174道菜谱（94家常菜、80早餐），不为扩充数量压缩验证。

## 下载与升级

手机在下方 Assets 下载 **cookdaily-v0.4.0.apk**，直接覆盖安装第二版或第三版，**不要先卸载**。本次包名不变，versionCode为4，继续使用原签名。安装后先核对旧收藏和清单。

## 本版功能

- 原生步骤计时提醒、通知声音/振动，按需开启通知和精确计时；未授权时明确标为“仅前台提醒”。另有系统时钟入口。声音仍受音量、勿扰、省电等设置影响，强行停止或重启后需重新计时。
- 空结果显示符合其他条件的最低用时；可取消用时限制并保留忌口。
- 食材别名、多食材组合、菜名首字母搜索，例如“西红柿 鸡蛋”“马铃薯”“hsr”。不承诺任意错别字搜索。
- 用量增加才取消对应已购买勾选，用量减少或移除其他菜时保留。新增食材默认未购买。
- 按个计数的食材给范围或切分提示；鸡蛋给蛋液克数，避免简单取整破坏比例。
- 设置页导出/导入 JSON 备份，包含收藏、清单、勾选、偏好、外观及做菜记录。导入有格式检查和替换确认；不恢复正在运行的计时。
- 深色/跟随系统，今天做过标记与最近记录，随机推荐尽量避开近7天做过的菜。
- 做菜大按钮、下一步防连点、触控锁、可选横屏；仅做菜时保持屏幕常亮。
- 过敏原醒目标签、成品图片搜索入口、外部教程的联网/登录/广告提示。
- 启动加载提示、release混淆构建；应用继续离线、无广告、无统计SDK。

## 使用提醒

开启后台计时：右上角齿轮 → 通知与声音、精确计时 → 返回菜谱重新开始计时。“交给系统时钟”需在时钟界面核对，结束也在时钟里操作。

图片入口是外部搜索，并非已核验或内置图片；菜谱尚未逐道厨房试做。正式图片库、进一步菜系扩充与全库步骤细化安排在后续阶段。
