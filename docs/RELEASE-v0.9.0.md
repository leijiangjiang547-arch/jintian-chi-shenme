# 今天吃什么 v0.9.0

第九版完善找菜入口、近似菜名和补菜反馈，并补入40道常见热菜。共340道图文菜谱：233道家常菜、107道早餐，图文全部离线内置。

## 下载与升级

下载 Assets 中的 **cookdaily-v0.9.0.apk**，先在旧版设置导出备份，再直接覆盖安装。**不要先卸载旧版**。沿用包名与签名，versionCode=9。

## 使用改进

- 首页在筛选条件之前提供醒目的“查看菜谱”大模块。进入完整菜谱库会清除搜索和临时发现条件，保留不吃辣及排除食材，避免放宽忌口。
- 搜“麻辣豆腐”等不标准名称时，展示“你可能想找”的相关菜名，点一下直接看做法。增加常见错字、别称、肉类部位和拼音匹配；候选不再只限4个。候选与严格搜索结果分开展示，不自动改词或参与随机抽选，仍遵守当前筛选条件。
- 首页、缺菜空状态、菜谱列表及设置提供补菜建议入口。可离线保存、更新同名备注和复制建议。点击“提交给我们”会打开本仓库公开 GitHub 草稿，需联网、登录并由用户确认提交；**只保存到本机不会发送给开发者**，请勿填写个人信息。
- 备份版本4包含补菜建议，兼容导入版本1、2、3；旧备份不会清空已有本机建议。保持旧收藏、清单、笔记、有效步骤进度及链接偏好。
- 修正叠加对话框的返回和提示位置；保存失败时保留补菜输入，并明确报告失败。

## 常见热菜

补入土豆烧排骨、土豆烧牛肉、梅菜扣肉、糖醋排骨、红烧排骨、黄焖鸡、干锅千页豆腐、红烧带鱼、酸菜炖粉条、蒜苗炒腊肉、丝瓜炒鸡蛋、玉米排骨汤等40道。每道7–9步，包含分次用料、火力、等待和检查点；原300道记录与步骤版本保持不变。

长时间泡洗、慢炖和蒸制计入预计用时，梅菜扣肉按顺序操作预计4小时40分钟。图片为按主要食材生成的成品参考，不是实拍；没有下载或分发平台图片、视频。菜系标签依据本家庭配方风味，不宣称唯一产地或覆盖穷尽。

来源支持范围和改编边界见 [A批来源](https://github.com/leijiangjiang547-arch/jintian-chi-shenme/blob/main/docs/v09-sources-a.json)、[B批来源](https://github.com/leijiangjiang547-arch/jintian-chi-shenme/blob/main/docs/v09-sources-b.json)。厨房尚未逐道试做，用时为编辑估计。
