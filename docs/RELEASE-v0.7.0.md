# 今天吃什么 v0.7.0

第七版重点补齐常见菜系、菜名别称和内容种类。共300道菜谱：193道家常菜、107道早餐，文字和AI成品示意图全部内置。

## 下载

在 Assets 下载 **cookdaily-v0.7.0.apk**。沿用原包名与签名，versionCode=7。建议先导出备份，再直接覆盖安装；**不要先卸载**。

## 内容与查找

- 补入干锅菜花、水煮肉片、红烧狮子头、荔枝肉、京酱肉丝等，八大菜系均有至少10道，另有京津、东北与西北风味。菜系用于本配方风味浏览，不表示唯一产地或穷尽全部菜式。
- 早餐扩展到107道，面条粉类仍为10道；本批增加蒸糕、包馅饼、谷物、烘蛋等不同做法。
- “干锅菜花 / 干锅花菜”可找到同一配方；补齐常见别称，支持全拼及首字母，例如 hongshaorou、hsr。精确菜名与别称排在食材相关结果之前。
- 无结果时可给出近似菜名，由用户点选；不会自动改搜索或解除忌口。
- 全部菜谱增加按菜系浏览入口与数量；列表按36道分批显示，扩充后避免首次同时渲染300张卡片。
- 本批120道配方均按独立操作、火力、定量材料、计时起点、状态检查整理，继续采用明确的分次用料引用。没有用新菜名替代旧菜ID。
- 新增120道离线AI成品示意图，清楚标记非实拍。长用时以小时显示，长步骤倒计时采用时分秒。教程入口、系统选择器、笔记和备份等第六版功能保留。

## 升级与证据

原180道菜的ID、图片与步骤版本保留，原收藏、清单、笔记与有效步骤进度应继续保留。存储与备份版本仍为3，支持导入版本1、2、3。

来源审计区分具体配方、相关技法与仅支持配料组合的资料；每道菜的参考链接可在详情下方展开。核查过程只放仓库文档，不塞入普通菜谱页面。新配方为家庭量化编排，时间为估计，未逐道厨房试做；AI图不用于判断熟透。
