# 今天吃什么 v0.6.0

第六版优化教程入口和做菜操作，继续核查菜谱内容。共180道：100道家常菜、80道早餐。

## 下载与升级

在下方 Assets 下载 **cookdaily-v0.6.0.apk**，约15.9 MB。沿用原包名、原签名，versionCode=6。**直接覆盖安装，不要先卸载**；建议先在设置中导出备份。

## 使用变化

- 视频搜索和相关视频移到详情前部，材料和步骤之前；详情首部同时显示人数、开始/继续做菜与买菜清单。
- 教程默认弹出手机系统的“选择打开方式”，可用浏览器或能打开链接的平台应用，不依赖Chrome。设置中可改为使用手机默认方式。
- 删除来源核查、改写说明等工作过程文案；保留折叠参考链接、必要过敏原与熟透提醒。首页较少用的条件收进“更多条件”，先选条件再抽菜的逻辑保持。
- 收藏页面明确区分没有收藏和筛选隐藏；可放宽筛选恢复浏览，并保留忌口。
- 手工勾选步骤后，继续入口定位最早未完成步骤；全部勾选可完成并记录。完成时取消本菜正在运行的计时，其他菜的计时保留；同一天同一道菜的记录不重复增加。
- 每道菜可保存个人做菜笔记，存在本机并随备份导出。备份版本3包含笔记和教程打开偏好，兼容导入版本1、2。

## 菜谱修订

重写木耳肉片、鱼香肉丝、宫保鸡丁、蒸水蛋、南瓜蒸蛋、肉末四季豆、香菇蒸滑鸡、海蛎煎的关键流程，检查分次调料、食材去向、熟透判断与计时起点。纠正部分早餐引用土豆/虾等错误检查文字，清理食谱中的编辑过程提示。

本轮28道内容调整，其中23道步骤版本变化。**这23道旧步骤进度会失效，收藏、清单与做菜笔记保留**；其他菜的进度继续保留。当前仍未逐道厨房试做，用时为估计。

## 检查与后续

29项核心自动测试、四组DOM回归通过；实际浏览器检查390px与320px手机宽度、深色844×390横屏。原生桥回归为模拟。release R8构建、包内资源字节、PNG、签名与校验已通过。

荣耀Magic6/荣耀400的覆盖安装、系统打开选择器、锁屏计时、文件选择器及真实厨房效果仍待体验确认。本次为试用预发布，未执行应用市场提交、收费或广告接入。
