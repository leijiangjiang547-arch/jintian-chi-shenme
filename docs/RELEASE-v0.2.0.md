# 今天吃什么 v0.2.0 · 菜谱扩充验收版

本次解决早餐种类重复和常见家常菜缺失：新增66道，总计166道（86道家常菜、80道早餐），并细化旧版韭菜鸡蛋盒子。

- 新增香蕉厚蛋烧、蓝莓西多士、虾滑馄饨面、饭团、烧卖、蒸糕等；补入红烧肉、回锅肉、可乐鸡翅、清蒸鲈鱼、锅塌豆腐、天津独面筋。
- 增加菜品种类、只看新增、不吃面条粉类筛选；随机推荐有条件时先换种类，再选一道。
- 新菜步骤的食材用量随人数换算，温度、厚度和每锅时间保持独立；补充锅具、搭配、熟透判断与来源核查说明。

手机请下载附件 cookdaily-v0.2.0.apk，直接覆盖旧版。包名与签名一致、版本递增；不要先卸载，以免丢失本机收藏。Source code 压缩包不是安装包。

验证：13项逻辑测试，166道详情/分步的 DOM 操作检查，APK资源比对、签名与校验和检查均通过。新版实际手机显示和覆盖安装仍待用户验收；全部菜谱尚未逐道厨房试做。当前是阶段更新，未宣称已覆盖全部菜系或达到商业上架标准。

优先验收：搜红烧肉；早餐勾选“不吃面条粉类”多次换一道；查看香蕉厚蛋烧和蓝莓西多士；切换1/2/3人份；检查旧收藏是否保留。做菜时记录用量、火力、实耗时间和难懂步骤。

后续按照 docs/ROADMAP.md 推进常见菜与菜系覆盖、来源/厨房验证、实用差异化和上架准备。明天由用户发消息继续，不自动运行。
