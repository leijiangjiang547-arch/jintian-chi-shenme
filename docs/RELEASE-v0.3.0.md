# 今天吃什么 · 第三版

先选适合自己的操作难度，再选想吃的菜系。

- “轻松做、日常做、挑战做”三档与全部难度，可和菜系、用时、食材排除、不吃辣同时使用；一键重置筛选。难度与耗时独立，不把整个菜系判为简单或困难。
- 菜系包括川、湘、鲁、粤、苏、浙、闽、徽，另有津菜、东北风味和家常风味；鲁菜支持山东菜搜索。当前各类为代表性覆盖，仍待逐步扩充。本阶段优先简单与日常家常菜，复杂候选留在下一阶段。
- 全部174道：94道家常菜、80道早餐。包括辣椒炒肉、油焖大虾、白灼菜心、龙井虾仁、虾仁烩干丝、海蛎煎、徽州一品锅等家庭配方。
- 应用界面显示现有菜品总量，不展示“新增”标记和修改痕迹。原有收藏、清单、按人数换算继续保留。

下载 cookdaily-v0.3.0.apk 覆盖安装，不要卸载旧版。请重点试用“轻松做/挑战做 + 菜系”、筛选无结果后的重置，以及旧收藏是否保留。

这是供用户继续实际验证的第三版，尚未上架应用市场。源代码、菜谱量化和程序测试不能替代厨房验证；全库步骤细化按照用户最新要求后置。菜谱并未逐道试做，难度为编辑估计，各菜系覆盖尚不充分。
